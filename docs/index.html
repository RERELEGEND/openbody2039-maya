MAYA

给 AI Agent 一个身体

让智能体不只会说话——她能挥手、点头、站立、表情变化。 OpenBody2039 把 身体知识 与 意图控制 做成通用 MCP， 任何 Agent 宿主都能接上虚拟人 MAYA。

打开 GitHub 读 MCP 文档

Agent 有脑，也该有身

语言模型擅长推理；缺的是可感知、可约束、可表演的身体层。

MAYA 不是又一个聊天皮肤。她有关节限位、实测轴语义、表情预设与站姿图谱—— Agent 先读懂身体，再用人话驱动。

挥手时仍可眨眼与微摆：控制是分层叠加的，像人，而不是木偶定格。

协议走标准 MCP stdio，不绑某一家 IDE。知识包离线可读；活体控制只需本地桥 + 兼容 viewer。

三步，让 Agent 长出身

发现 → 查询 → 意图。优先原语，而不是逐关节拧角。

  1. 发现 MAYA

    调用 openbody_info，拿到能力清单与推荐流程。

  2. 读身体图谱

    body_lookup("RightArm") 或 Resources openbody://body-graph/*——骨名与限位不靠猜。

  3. 意图驱动

    intent_do("挥右手打招呼") → 规划原语 → 平滑播放 → control_release。
