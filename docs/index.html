MAYA

Give AI Agents a Body

Agents already think. MAYA lets them move — wave, nod, stand, and express — through a universal MCP of body knowledge and intent-level control.

View on GitHub Read the MCP docs

A mind needs a body

Language models reason well. What’s missing is a constrained, performable body layer.

MAYA is not another chat skin. She ships joint limits, measured axis semantics, expression presets, and standing poses — so an agent can read the body, then drive it in plain language.

Wave while still blinking and breathing: control is layered, like a person — not a frozen puppet.

Standard MCP stdio, host-agnostic. Knowledge works offline; live motion needs a local bridge and any OpenBody-compatible viewer.

Three steps to embodiment

Discover → look up → act. Prefer primitives over per-joint tweaks.

  1. Meet MAYA

    Call openbody_info for capabilities and the preferred flow.

  2. Read the body graph

    body_lookup("RightArm") or resources openbody://body-graph/* — never invent bone names.

  3. Drive by intent

    intent_do("wave right hand hello") → plan primitives → play → control_release.
